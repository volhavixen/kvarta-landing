# Кварта: лендинг обжарки

Сайт: https://kvarta-landing-one.vercel.app/. 
Макет: `mockups/combined.html` (выбор и правки в `mockups/README.md`).

**Стек.** Next.js (App Router, TypeScript), один маршрут `POST /api/lead`. Заявки в Upstash Redis (на бесплатном Vercel файловая система только для чтения; защита от дублей одной командой `SET NX EX 600`), копия в Telegram. Запуск: `npm i`, `.env.local` по `.env.example`, `npm run dev`. Тесты: `npm test`, `npm run e2e`.

**Lighthouse mobile (живой сайт):** Performance 98, Accessibility 100, Best Practices 100, SEO 100. Отчёты: `docs/lighthouse/`.

## Что делали сами, а что ИИ

Сами: выбор макета и правки по шрифтам и текстам; требования и допущения, решение по хранилищу, проверка в браузере.
ИИ (Claude Code): план по брифу, логика с тестами (телефон, дата обжарки, калькулятор, API), перенос макета в компоненты, e2e-тесты, Lighthouse, защита от спама.

## Где ИИ ошибся и как заметили

- Бриф-PDF не прочитался (нет текстового слоя), план был по выжимке. Заметили сразу, поставили `poppler`, перечитали все страницы.
- Тест с неверным ожиданием даты (для среды «завтра», а не «в четверг»): упал до реализации, исправили тест.
- Обработчик заявки в `route.ts` не заводится (Next.js не пускает лишние экспорты): вынесли в `lib/handle-lead.ts`.
- ИИ косячил при внесении правок, терял адрес нужной папки, едва не задублировал часть проекта, написал не самые лучшие тексты, стабильно не соблюдает минимальные размеры и контрастность шрифтов. Защиту от спама не предусмотрел в плане работы. Сайт написал быстро, большую часть времени заняли правки, доработки и тесты результатов, а также регулярные проверки, все ли закоммитил, ничего ли не пропустил, выполнил ли весь объем работы по требованиям или что-то пропустил.

## Что не успели или сделали бы иначе

- Телефон мастерской `+375 29 000-00-00` — заглушка;
- Telegram и Upstash работают, но проверены не на реальных данных заказчика.
- Заголовки на кириллице рисуются запасным шрифтом (у DM Serif Display нет кириллицы).
- Допущения: обжарка Колумбии средняя, Бразилии средне-тёмная; доставка до 50 BYN по согласованию с менеджером.
